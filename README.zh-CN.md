# Git Compare for Code

在 VS Code 中，将 Git 项目的当前工作区与分支、标签或提交进行比较。在源代码管理侧栏按目录浏览变更文件，点击即可使用 VS Code 原生差异编辑器查看差异。

## 功能

- 将整个仓库或单个目录与本地分支、远程跟踪分支、标签或提交 ID 比较。
- 查看工作区差异，涵盖已暂存、未暂存及未跟踪文件。
- 按目录浏览变更，并按文件路径或变更状态筛选。
- 在左侧查看目标版本，在右侧编辑当前文件。
- 切换比较目标时保留当前目录范围和筛选条件。
- 支持工作区内多个仓库的选择，以及 Git worktree。

比较操作不会切换分支，也不会修改 Git 暂存区。

## 环境要求

- VS Code 1.85 或更新版本。
- Git 已安装且可通过 `PATH` 访问。
- 已启用 VS Code 内置 Git 扩展。
- 工作区已受信任，且包含 Git 仓库。

## 安装

从源码打包安装时，请先准备 Node.js 和 npm，然后在仓库根目录执行：

```sh
npx @vscode/vsce package
```

在 VS Code 命令面板执行 **Extensions: Install from VSIX…**（从 VSIX 安装），选择生成的 `.vsix` 文件。

## 使用方法

### 比较项目

1. 在 VS Code 中打开 Git 仓库。
2. 从命令面板执行 **Git: Compare Project…**，或点击 **Source Control**（源代码管理）下 **Git Compare** 视图的比较按钮。
3. 如果工作区包含多个仓库，先选择仓库。
4. 选择分支或标签，或选择 **Enter Commit ID…**，输入完整或缩写的提交哈希。
5. 在 **Git Compare** 中浏览结果，点击文件打开差异编辑器。

左侧显示选定的目标版本，右侧显示当前工作区文件；当前文件存在时，可直接编辑右侧。新增和未跟踪文件的左侧为空，已删除文件的右侧为空。

视图仅显示最近一次比较。开始新的项目或目录比较会替换之前的结果，并重置路径和状态筛选。

### 比较目录

在资源管理器中右键点击目录，选择 **Compare This Folder…**，然后选择目标版本。结果仅包含所选目录内的变更，Git Compare 视图顶部会显示完整比较范围。

### 管理比较结果

| 操作 | 行为 |
| --- | --- |
| **Compare Project…** | 开始新的仓库比较，并重置筛选。 |
| **Change Target…** | 更换目标版本，保留仓库、目录范围和筛选条件。 |
| **Refresh** | 重新解析目标引用，并从已保存文件重新读取差异。 |
| **Filter Files…** | 对仓库相对路径进行不区分大小写的子串匹配；输入留空可清除路径筛选。 |
| **Filter Status…** | 显示所有变更，或仅显示修改（`M`）、新增（`A`）、删除（`D`）、未跟踪（`?`）文件。 |
| **Expand All** | 展开结果中的所有目录。 |
| **Clear** | 清空当前比较并重置筛选。 |

这些操作可从视图工具栏及其 **…** 菜单访问。路径和状态筛选同时生效。**No differences** 表示没有发现差异；**No matching files** 表示筛选条件隐藏了所有结果。

## 比较规则与限制

- 比较结果反映已保存的工作区相对于目标版本的差异，已暂存与未暂存修改合并展示。不包含被忽略的未跟踪文件。
- 保存文件后，使用 **Refresh** 更新文件列表。未保存的修改不会影响文件列表；已打开的差异编辑器右侧遵循 VS Code 原生编辑器的缓冲区行为。
- 远程分支使用本地已有的远程跟踪引用。如需更新引用，请自行执行 `git fetch`。
- 刷新会重新解析目标引用，因此分支或标签移动后，结果可能变化。已打开的历史差异固定到打开时使用的提交；刷新或切换目标后，请重新点击文件打开更新后的比较。
- 重命名显示为删除和新增。
- 历史内容按 UTF-8 文本读取，二进制文件、其他编码及子模块内部变化暂不支持完整比较。

## 开发

扩展使用 JavaScript、VS Code 扩展 API 和 Git 命令行，未声明 npm 依赖。

用 VS Code 打开本仓库，按 **F5** 使用内置启动配置运行 Extension Development Host。在新窗口中打开 Git 项目，即可体验扩展。

在仓库根目录运行测试和语法检查：

```sh
npm test
npm run check
```

测试使用 Node.js 内置测试运行器。后端测试会创建临时 Git 仓库；扩展测试使用模拟的 VS Code API。
