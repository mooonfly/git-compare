# Changelog

## 0.0.1

- Compare an entire Git repository or a selected folder with a branch, tag, or commit.
- Browse changes in a directory tree under Source Control and open files in the native VS Code diff editor.
- Include staged, unstaged, and untracked files in working-tree comparisons.
- Filter results by repository-relative path and change status.
- Refresh comparisons, change targets while preserving filters, and expand all result directories.
- Support multiple repositories and Git worktrees.
- Provide English and Simplified Chinese documentation.
